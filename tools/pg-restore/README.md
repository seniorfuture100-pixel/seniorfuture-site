## 3. 되돌리기 순서 (파트너 다시 열기)

0. **먼저:** 정산대행 계약 또는 토스 확인 (위 ⚠️ 참고)
1. 되돌릴 수 있는지 확인: `node tools/pg-restore/restore.js --check`
   - 스위치가 '켜짐'이고 문구 **7곳이 '되돌림'** 으로 나와야 해요. 0곳이면 누가 문장을 바꾼 거라 손으로 확인해요.
2. 저장소 되돌리기: `node tools/pg-restore/restore.js`
   - 스위치를 끄고 약관 파일 3개를 원래대로 돌려요.
3. 빌드·배포 (평소 공통 코드 배포와 같아요)
   - `git fetch --tags`로 다음 번호를 확인해요.
   - `node tools/site/jsbuild.js` → `cssbuild.js` → `bundle.js v1.0.NNN` → `tools/check/lint.js` → `PW_CHANNEL=chrome node tools/check/smoke.js`
   - 커밋·태그·푸시
4. 시험 모드 확인
   - 홈 '파트너 모집' 배너와 헤더 '파트너 지원' 버튼이 다시 보이는지
   - /partner가 열리는지
   - 약관에 파트너 탭이 다시 보이는지
5. Header Code 저장: 운영 코드가 직전 버전 loader와 같은지 확인한 뒤 새 loader로 바꿔 저장 → 손님 HTML 버전 확인
6. 아임웹 문구 3곳: 약관 위젯(디자인 모드 › 약관 및 정책 › 코드 설정), 관리자 › 약관 › 이용약관, 관리자 › 약관 › 개인정보처리방침
   - 각 화면에서 아래 코드를 실행한 뒤 '저장'을 누르고, 다시 열어서 확인해요.
7. **게시 (사장님)** → 손님 화면 확인 → `restore.js --check`에서 문구가 '없음'으로 나오면 끝

```js
// 아임웹 화면에서 실행 — 코드 편집기(monaco) 또는 관리자 약관 칸(textarea)이 열린 상태
const { pairs } = await (await fetch('https://raw.githubusercontent.com/seniorfuture100-pixel/seniorfuture-site/qa/1026/tools/pg-restore/pairs.json', { cache: 'no-store' })).json();
const applyPairs = t => { for (const p of pairs) { const n = t.split(p.now).length - 1; if (n > 1) throw new Error(p.name + ' ' + n + '번'); if (n) t = t.replace(p.now, p.orig); } return t; };
// 디자인 모드(약관 위젯):
//   const ed = monaco.editor.getEditors()[0]; ed.executeEdits('sf', [{ range: ed.getModel().getFullModelRange(), text: applyPairs(ed.getValue()) }]);  → 편집기 '저장'
// 관리자 약관(이용약관·개인정보처리방침):
//   const ta = document.querySelector('textarea'); Object.getOwnPropertyDescriptor(HTMLTextAreaElement.prototype, 'value').set.call(ta, applyPairs(ta.value)); ta.dispatchEvent(new Event('input', { bubbles: true }));  → '저장'
```

**다시 숨길 때 (반대로):** `config.js`를 `SF_PG_HIDE = true`로 바꾸고, `pairs.json`의 orig → now 방향으로 문구를 바꾼 뒤 3~7번을 그대로 하면 돼요.
