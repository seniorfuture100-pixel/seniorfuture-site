**1. 판매 구조**

시니어퓨처는 시니어 산업 실무 교육(온라인·오프라인 강의, 무료 라이브, 커뮤니티 모임)을 **자기 이름으로 직접 판매**합니다.

- 사이트의 모든 상품은 시니어퓨처가 판매자로서 수강생과 직접 계약합니다.
- 결제대금은 전액 시니어퓨처 정산 계좌로 입금됩니다.
- 결제, 취소, 환불과 수강생 응대 책임은 모두 시니어퓨처가 집니다.
- 다른 판매자가 입점해 자기 상품을 파는 오픈마켓 구조가 아니며, 결제대금을 제3자에게 나누어 정산하지 않습니다.

**2. 강사(파트너)에 대한 지급**

강의를 맡는 강사(파트너)는 시니어퓨처와 강의·콘텐츠 용역 계약을 맺습니다.

- 시니어퓨처는 이 계약에 따른 **강사료(용역 대가)** 를 회사 자금으로 지급하고, 관련 세금을 원천징수합니다.
- 이 지급은 결제대금을 파트너에게 이전하거나 분배하는 것이 아닙니다.
- 사이트의 파트너 안내와 파트너 이용약관에도 이 내용을 명시했습니다.
  - 파트너 지원 페이지 '자주 묻는 질문' Q5
  - 파트너 이용약관 제1조

**3. 추천(마케팅 파트너스) 프로그램**

회원이 추천 링크로 다른 이용자에게 강의를 소개해 결제가 확정되면, 시니어퓨처가 **사이트 포인트(적립금)** 를 지급합니다.

- 포인트는 다음 강의·모임 결제에만 쓸 수 있습니다.
- 현금으로 바꾸거나 다른 사람에게 넘길 수 없습니다. 근거는 마케팅 파트너스 이용약관 제7조입니다.

**4. 신청서 수정**

입점 신청서의 판매 방식을 '통신판매중개업'에서 **'해당없음(직접 판매)'** 으로 바로잡아 다시 제출합니다.
