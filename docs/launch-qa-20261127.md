## 운영 반영 및 차단

- 아임웹 관리자 접근 시 로그인 화면으로 이동한다. Header Code 교체 및 관리자 원본 위젯 수정은 차단 상태다.

## 런칭 전 내용 결정 필요

1. 교육 115의 판매가 10,000원과 상세 이미지 내 금액이 다르다. 테스트 가격이라는 이전 지시가 있어 임의 변경하지 않았다.
2. 무료 라이브 썸네일의 12.16(화)와 2026년 요일이 맞지 않는다. 일정은 사용자 확정 필요.

4. 홈은 분야별 VOD를 안내하지만 현재 공개 교육 목록은 온라인 라이브·스터디다. 실제 제공 상품 범위 확인 필요.

6. 기업 협업 통계 20건+/30건+ 등 페이지별 집계 범위 설명이 필요하다. 수치는 임의 통일하지 않는다.
7. 약관 시행일, 환불·추천 적립 조건은 운영 확정본과 대조가 필요하다. 법적 적합성을 보증하는 검사는 하지 않았다.
