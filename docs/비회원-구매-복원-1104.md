# 비회원 구매 — PG 심사용 임시 설정과 복원 순서 (11/4)

비회원 구매는 PG사(토스페이) 심사 요청에 맞춰 잠시 켠 것이에요. 심사가 끝나면 아래 순서로 되돌려요.

## 11/4에 바뀐 것 (비회원 관련 전부)

| 어디 | 바뀐 것 | 원래 |
|---|---|---|
| 아임웹 관리자 › 쇼핑 설정 › 주문 › 기본 설정 | '비회원 주문 허용' 켬 | 이미 켜져 있었음 (11/4 이전부터) |
| 같은 곳 | '로그인 전 바로 주문 허용' 켬 (사장님이 켬) | 꺼짐 |
| 사이트 코드 v1.0.217 (운영 반영 11/4) | 로그인 창·로그인 페이지에 아임웹 '비회원 주문배송 조회' 버튼 보이기 (css patch/51, 53b) | 숨김 (v1.0.215) |
| 같은 버전 | 비회원 결제 완료 화면: '마이페이지' 대신 '주문 조회'(→ /login) 안내 (js patch/25) | 모두 '마이페이지' |

v1.0.216 은 만들었다가 되돌린 버전이라 운영에 나간 적 없어요.
상품 설정(82·84·103)은 바꾸지 않았어요.

## 복원 순서 (심사 끝난 뒤)

1. **아임웹 관리자 › 쇼핑 설정 › 주문 탭**
   - '로그인 전 바로 주문 허용' 끄기
   - '비회원 주문 허용'은 11/4 전부터 켜져 있던 값이에요. 회원만 구매하게 하려면 이것도 끄기
   - 위 '저장' 누르기 → 새로고침해서 꺼진 것 확인
2. **사이트 코드 되돌리기**: v1.0.217 커밋(6f9fb41)만 되돌린 새 버전을 만들어 배포
   ```
   git pull --ff-only; git fetch --tags
   git revert --no-edit 6f9fb41
   node tools/site/jsbuild.js; node tools/site/cssbuild.js; node tools/site/bundle.js v1.0.NNN
   node tools/check/lint.js; PW_CHANNEL=chrome node tools/check/smoke.js
   ```
   커밋·태그·푸시 → 관리자 SEO › Header Code 에 새 header-loader 넣고 저장.
   - 그 사이 다른 배포가 없었다면(운영이 아직 v1.0.217이면) Header Code 를 **v1.0.215 header-loader** 로 바꾸기만 해도 같은 결과예요.
3. **확인** (로그인 안 한 새 창)
   - /course/?idx=82 '수강 신청하기' → 로그인 창이 떠야 함 (결제 화면으로 바로 가지 않음)
   - /login 화면에 '비회원 주문배송 조회' 버튼이 없어야 함
   - 회원으로 로그인해서 82 신청 → 결제 화면 정상

## 주의
- 심사 기간에 들어온 비회원 주문이 있으면, 복원 전에 관리자 › 주문에서 처리해 두기. 복원 뒤에는 그 손님이 사이트에서 주문을 조회할 버튼이 없어요(주문 안내 메일·문자로 안내).
- 시험할 때는 /shop_view 가 아니라 /course·/live 주소로, 휴대폰은 화면 390 + 터치로(모바일 기기 흉내 모드는 좌표가 어긋나요).
