# 상품 상세 등록 안내 (교육 · 무료 라이브 · 커뮤니티 공통, 2026-10-27~)

세 종류 모두 상세페이지가 같은 흐름이에요.

| | 탭 1 | 탭 2 | 탭 3 | 탭 4 | 탭 아래 |
|---|---|---|---|---|---|
| 교육 | 소개 | 프로그램 | 강사 | 후기 | 자주 묻는 질문 |
| 무료 라이브 | 소개 | 프로그램 | 연사 | 후기 | 자주 묻는 질문 |
| 커뮤니티 | 소개 | 프로그램 | 호스트 | 후기 | 자주 묻는 질문 |

- 커뮤니티는 탭 위에 '모임 안내'(일시·장소·마감) 상자가 자동으로 붙어요.
- '후기'는 수강평 게시판에서 자동으로 와요. 쓰지 않아도 돼요.
- 휴대폰은 탭 줄 없이 같은 순서로 아래로 이어져요.

## 쓰는 곳
아임웹 관리자 › 쇼핑 › 상품 › 상품 편집 › **상품 상세 설명 → '에디터로 등록'**
(‘이미지로 등록’·‘모바일 전용 상세 설명’은 쓰지 않기 — PC 상세 설명 하나로 휴대폰까지 보여요)

## 틀 (복사해서 내용만 바꾸기)
대괄호 줄은 **그 줄에 제목만** 쓰고 엔터, 그 아래에 내용을 써요. 사진·표·영상도 칸 안에 넣을 수 있어요.

```
[소개]
이 과정은 어떤 분께, 무엇을 얻어 가게 하는지 2~3줄로 써요.
(소개 사진은 '이미지 첨부'로 이 아래에)

[프로그램]
1회차 · 주제
2회차 · 주제
3회차 · 주제

[강사]            ← 무료 라이브는 [연사], 커뮤니티는 [호스트]라고 써도 같아요
이름 · 한 줄 경력
소개 2~3줄

[자주 묻는 질문]
Q. 질문
A. 답
Q. 질문
A. 답
```

- 안 쓴 칸은 탭이 생기지 않아요(예: [강사]를 안 쓰면 소개·프로그램·후기만).
- `[소개]` 줄 없이 맨 위에 쓴 글도 '소개'로 들어가요.
- 예전에 쓰던 제목도 알아서 묶어요
  - 프로그램: `[커리큘럼]` `[진행 안내]` `[프로그램 일정]` `[일정]`
  - 강사 칸: `[강사 소개]` `[연사]` `[연사 소개]` `[호스트]`
  - 소개 칸: `[프로그램 소개]` `[강의 소개]` `[모임 소개]` (그 밖의 제목, 예 `[이런 분께 추천해요]`는 소개 칸 안 소제목으로)
  - 자주 묻는 질문: `[자주 묻는 질문]` `[FAQ]` `[문의]`
- 자주 묻는 질문은 `Q.`로 시작하는 줄이 질문, 그 아래 `A.`로 시작하는 줄(과 다음 줄들)이 답이에요. Q 줄이 없으면 쓴 내용이 '자주 묻는 질문' 한 항목으로 들어가요.
- '자주 묻는 질문' 맨 아래에는 **교환·환불 안내**(상품 상세 하단 공통 글)와 **상품 문의**(아임웹 문의 게시판 — 손님이 여기서 질문을 남겨요)가 자동으로 붙어요.

## 그 밖에
- 카테고리: 교육 / 무료 라이브 / 모임 중 하나
- 무료 라이브 일시: 상품명 끝에 `[2026/11/20 19:30]`
- 꼬리표: 상품 강조 설정 › 상품 배지 체크칸 (베스트 → BEST, 주문폭주 → 인기급상승, 오늘출발 → 얼리버드, MD추천 → 선착순 한정)
- 외부 채널 노출(네이버쇼핑 등)은 필요한 상품만 켜기
- 점검용 상품: `[테스트] 상세 틀 점검용 …` 3개(교육·무료 라이브·커뮤니티) — 런칭 전 숨김 또는 삭제
