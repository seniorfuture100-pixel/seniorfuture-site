# 상품 상세 등록 안내 (교육 · 무료 라이브 · 커뮤니티 공통, 2026-10-27 v2~)

세 종류 모두 상세페이지가 같은 흐름이에요.

| | 탭 1 | 탭 2 | 탭 3 | 탭 4 | 탭 아래 |
|---|---|---|---|---|---|
| 교육 | 소개 | 프로그램 | 강사 | 후기 | 더 알아보기 |
| 무료 라이브 | 소개 | 프로그램 | 연사 | 후기 | 더 알아보기 |
| 커뮤니티 | 소개 | 프로그램 | 호스트 | 후기 | 더 알아보기 |

- 본문에는 '소개'·'프로그램'·'강사 소개' 같은 큰 제목이 보이지 않아요(탭으로 이동).
- 커뮤니티는 탭 아래에 '모임 안내'(일시·마감) 상자가 자동으로 붙어요.
- '후기'는 수강평 게시판에서 자동으로 와요. 쓰지 않아도 돼요.

## 1. 공통으로 채우는 칸 (관리자 › 쇼핑 › 상품 › 상품 등록)

| 칸 | 교육 | 무료 라이브 | 커뮤니티 |
|---|---|---|---|
| 카테고리 | 교육 | 무료 라이브 | 모임 |
| 상품명 | 강의 제목 | 제목 `[2026/11/30 19:30]` | 제목 `[2026/11/28 14:00]` |
| 판매가 | 금액 | **0** (비우면 저장 안 됨) | 참가비 (무료면 0) |
| 대표 이미지 | 16:9 | 16:9 | 16:9 |
| 상품 배지 | 베스트→BEST · 주문폭주→인기급상승 · 오늘출발→얼리버드 · MD추천→선착순 한정 | 같음 | 같음 |
| 상품 상세 설명 | 아래 틀 | 아래 틀 (`[강사]` 대신 `[연사]`도 됨) | 아래 틀 (`[호스트]`도 됨) |

- 상품명 끝 `[날짜 시간]`은 화면 제목에서 빠지고, 라이브는 카운트다운·일시, 모임은 '모임 안내'로 나와요.
- 상세 설명은 **'에디터로 등록'** 하나만 써요(이미지로 등록·모바일 전용 상세 설명은 쓰지 않기).
- 모임 장소는 `[소개]` 안에 한 줄로 써 주세요.

## 2. 상품 상세 설명 틀 (복사해서 내용만 바꾸기)
대괄호 줄은 **그 줄에 제목만** 쓰고 엔터, 그 아래에 내용을 써요.

```
[소개]
이 과정은 어떤 분께, 무엇을 얻어 가게 하는지 2~3줄
(사진·표·영상도 이 아래에 넣을 수 있어요)

[프로그램]
총 6회 · 회당 90분 · 온라인 라이브        ← 첫 줄 = 설명(자유롭게)
# 시니어 시장 구조 한눈에 보기 | 90분      ← '#' 줄 = 1회, 2회 … (번호는 자동)
- 시장 규모와 성장 흐름                    ← '-' 줄 = 그 회차 안 세부 내용
- 1강 맛보기 영상                          ← 이 글자에 링크를 걸면 파란 글씨 ▶ + '미리보기'
# 고객 인터뷰 실습 | 90분
- 인터뷰 질문지 만들기

[강사]
김난도                                     ← 전문가 네트워크에 있는 이름이면 사진·분야·소속·함께한 주제가 자동으로
트렌드 코리아 저자, 20년간 …              ← 이름 다음 줄 = 카드 안 소개 글
```

- 회차는 기본으로 **모두 펼쳐진 상태**예요. 시간(`| 90분`)은 없어도 돼요.
- 미리보기 링크: 에디터에서 글자를 선택하고 링크 버튼으로 주소를 넣어요(또는 줄 끝에 주소를 붙여 써도 돼요).
- 예전처럼 `1회차 · 주제 (90분)`으로 쓴 줄도 회차로 읽어요.
- 강사 이름이 전문가 네트워크(/experts)에 없으면 쓴 글이 그대로 보여요. 새 강사는 전문가 네트워크에 먼저 추가해 주세요.
  여러 명이면 이름 줄을 여러 번 쓰면 돼요.
- 안 쓴 칸은 탭이 생기지 않아요.
- 예전 제목도 알아서 묶어요: 프로그램 `[커리큘럼]` `[진행 안내]` `[일정]` / 강사 `[강사 소개]` `[연사]` `[호스트]`

## 3. 더 알아보기 (모든 상품 공통 — 한 번만)
아임웹 관리자의 **상품 상세 상단/하단 공통** 설정(하단 공통 칸)에 아래처럼 써 두면 모든 상품 맨 아래 '더 알아보기'에 제목-펼치기로 나와요.

```
[운영 정책]
수강 기간, 다시보기, 자료 이용 규칙 등

[환불 규정]
개강 전 100% 환불 · … 
```

- 지금 하단 공통 글(`<교환 및 반품 가능 기간>` …)은 제목이 없어 '환불 규정' 하나로 보여요.
- 상품 문의 게시판은 더 이상 보이지 않아요.
- 상품 상세 설명에 `[자주 묻는 질문]`(Q./A. 줄)을 쓰면 운영 정책·환불 규정 뒤에 이어 붙어요. 안 쓰면 안 나와요.

## 그 밖에
- 외부 채널 노출(네이버쇼핑 등)은 필요한 상품만 켜기
- 점검용 상품: `[테스트] 상세 틀 점검용 …` 3개(62·63·64) — 런칭 전 숨김 또는 삭제
