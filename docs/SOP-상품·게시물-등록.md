## 1. 상품 (쇼핑 › 상품)

### 1-1. 교육 상품 새로 열기
- **어디서** 관리자 › 쇼핑 › 상품 › 오른쪽 위 [상품 등록] › 일반 상품
- **무엇을**
  1. 상품 정보: 대표 이미지(16:9) · 상품명 `강의명 N기` · 카테고리 `교육`
  2. 상품 상세 설명(에디터로 등록)에 아래 칸을 붙여 넣고 내용만 바꾸기
     ```
     [소개]
     누구를 위한, 무엇을 얻는 과정인지 2~3줄
     [프로그램]
     총 4회 · 회당 90분 · 온라인
     1회차 제목 (90분)
     - 세부 내용
     [강사]
     홍길동
     [수강 기간]
     2026.11.01 - 2026.12.31
     [톡방]
     https://open.kakao.com/o/…
     [강의 영상]
     ```
  3. 가격: 판매가 · (필요하면) 옵션
  4. 상품 강조 설정: 배지(BEST·인기급상승·얼리버드·선착순) 선택
  5. 판매 설정: 판매중 → [저장]
- **보이는 곳** 교육 목록·상품 상세 / 결제한 회원의 마이페이지 › 나의 강의실 → 강의실(`/class?idx=번호`) 자동

### 1-2. 무료 라이브 열기
- **어디서** 1-1과 같음
- **무엇을** 카테고리 `무료 라이브` · 상품명 `제목 [2026/11/30 19:30]` · 판매가 `0` · 상세는 `[소개] [프로그램] [연사]`
- **보이는 곳** 무료 라이브 목록(카운트다운·일시 자동) · 신청자 나의 강의실
- **Zoom 링크**: 지금은 사이트 코드에 넣는 방식 → 링크를 개발 담당에게 전달

### 1-3. 커뮤니티(모임) 열기
- **어디서** 1-1과 같음
- **무엇을** 카테고리 `모임` · 상품명 `제목 [2026/11/28 14:00]` · 참가비(무료면 0) · 상세 `[소개]`(장소 한 줄 포함) `[프로그램]` `[호스트]`
- **보이는 곳** 커뮤니티 목록 · 상세 '모임 안내'(일시) 자동

### 1-4. 강의 영상 올리기 (회차가 끝날 때마다)
1. 녹화 파일(또는 강사가 드라이브에 올린 파일) 받기
2. Vimeo › 강의 폴더에 업로드 → 공개 범위 '비공개(링크)' · 삽입 '우리 사이트에서만'
3. 관리자 › 쇼핑 › 상품 › 해당 상품 › 상품 상세 설명 `[강의 영상]` 아래에 `3회차 https://vimeo.com/…` 한 줄 추가 → [저장]
- **보이는 곳** 강의실 3회차 '공개 예정' → '바로보기'

### 1-5. 톡방 주소 바꾸기
- 해당 상품 › 상품 상세 설명 `[톡방]` 아래 주소만 바꾸고 [저장] → 나의 강의실·강의실 '톡방 입장' 버튼에 바로 반영

### 1-6. 다음 기수 열기
- 상품 목록 › 지난 기수 상품 오른쪽 [⋮] › 복제 → 새 상품에서 상품명(N기) · `[수강 기간]` · `[톡방]` 수정, `[강의 영상]` 줄은 비우기 → 판매중 → [저장]

### 1-7. 모집 마감
- 해당 상품 › 판매 설정: **품절** 또는 판매기간 설정 → [저장]
- **'숨김'은 모든 수강 기간이 끝난 뒤에** (숨기면 수강생 강의실이 비어요)
