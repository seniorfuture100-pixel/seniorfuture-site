## A. 상품 등록 (관리자 › 쇼핑 › 상품 › 상품 등록 › 일반 상품)

### 1. 기본 칸
| 칸 | 교육 | 무료 라이브 | 커뮤니티 |
|---|---|---|---|
| 카테고리 | 교육 | 무료 라이브 | 모임 |
| 상품명 | `강의 제목 N기` | `제목 [2026/11/30 19:30]` | `제목 [2026/11/28 14:00]` |
| 판매가 | 수강료 | **0** | 참가비(무료면 0) |
| 대표 이미지 | 16:9 | 16:9 | 16:9 |
| 상품 배지 | BEST · 인기급상승 · 얼리버드 · 선착순 중 필요한 것 | 같음 | 같음 |
| 옵션 | 필요하면(추가 금액 가능) | 없음 | 필요하면 |

- 상품명 끝 `[날짜 시간]` = 라이브 카운트다운·일시 / 모임 안내 일시로 자동 표시
- 상세 설명은 **'에디터로 등록'** 하나만 사용
- 외부 채널 노출(네이버쇼핑 등)은 필요한 상품만 켜기

### 2. 상세 설명 (대괄호 줄 = 그 줄에 제목만 쓰고 엔터)
```
[소개]
누구를 위한, 무엇을 얻는 과정인지 2~3줄 (모임은 장소도 여기)

[프로그램]
총 4회 · 회당 90분 · 온라인            ← 첫 줄 = 설명
1회차 제목 (90분)                      ← 회차
- 세부 내용                            ← 회차 안 세부

[강사]                                 ← 라이브는 [연사], 모임은 [호스트]도 가능
홍길동                                 ← 전문가 네트워크 이름이면 사진·소속 카드 자동

[수강 기간]                            ← 교육만
2026.11.01 - 2026.12.31                ← 기수제(고정 날짜) / VOD는 '결제일부터 90일'

[톡방]                                 ← 화면엔 안 보임, 나의 강의실 '톡방 입장' 버튼
https://open.kakao.com/o/…

[강의 영상]                            ← 화면엔 안 보임, 영상이 생길 때마다 한 줄씩
1회차 https://vimeo.com/…
```
- 안 쓴 칸은 탭·버튼이 생기지 않아요.
- 전체 영상 주소는 **반드시 `[강의 영상]`에만**. `[프로그램]` 세부 줄에 링크를 걸면 누구나 보는 '미리보기'가 돼요.
- 새 강사는 **전문가 네트워크 글을 먼저** 쓰기(B-5).
- '더 알아보기'(운영 정책 · 환불 규정)는 **자동**(쇼핑 설정 › 상품 상세 하단 공통). 상품마다 쓰지 않아요.

### 3. 등록 후 자동으로 되는 것 (할 일 없음)
- 결제한 회원: 마이페이지 › 나의 강의실 카드(수강 기간·D-day·강의실 입장·톡방 입장)
- 강의실: 공용 페이지 `/class?idx=상품번호` — 결제(0원 신청 포함)한 회원에게만 커리큘럼·바로보기
- 환불·취소되면 나의 강의실·강의실에서 자동으로 빠짐, 수강 기간이 끝나면 버튼 꺼짐

### 4. 운영 중 할 일
| 언제 | 할 일 |
|---|---|
| 회차가 끝나면 | 녹화 → Vimeo 업로드('우리 사이트에서만 재생') → 상세 `[강의 영상]`에 한 줄 추가 |
| 톡방 주소 바뀜 | 상세 `[톡방]` 주소만 바꾸기 |
| 다음 기수 | 지난 상품 **복제** → 상품명(N기)·`[수강 기간]`만 수정 |
| 모집 끝 | **'숨김' 금지**(강의실이 비어요) → 품절·판매 기간 종료로. 모든 수강 기간이 끝난 뒤 숨김 |
| 무료 라이브 Zoom 링크 | 지금은 코드 설정(SF_SITE.items) → 링크를 받으면 반영 요청 |

### 5. 마지막 점검
- [ ] 관리자 미리보기(`/shop_view/?idx=번호&preview_mode=1`)에서 탭·회차·강사 카드 확인
- [ ] 휴대폰 화면 확인
- [ ] 테스트 주문은 0원 상품으로만

## C. 입력폼 (관리자 › 콘텐츠 › 입력폼에서 접수 확인)
- 기업·공공기관 협업 문의: 기업/기관명 · 담당자명 · 연락처 · 이메일 · 협업 유형 · 문의 내용 · 예산(8구간) · 참고 URL
- 파트너 지원 신청: (신청 분야 자동) · 이름 · 연락처 · 이메일 · 소속/직급 · 자기소개 · 경력사항 · 참고 링크 · 이력서 파일 · 프로그램 설명
- 칸 수정은 디자인 모드 › 입력폼 위젯 › 입력폼 설정(바로 저장). **칸을 지우면 그 칸의 접수 데이터도 지워져요.**

## D. 하지 않는 것
- 디자인 모드 '게시하기'는 확인 후 사장님이 직접
- 테스트 중 카카오톡·문자 발송 버튼 누르지 않기
- 공용 강의실 페이지(`/class`)와 그 안 코드 위젯은 고치지 않기
