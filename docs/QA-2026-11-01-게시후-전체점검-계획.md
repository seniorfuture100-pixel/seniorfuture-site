## 3. 문제 등급과 고치는 방법
- 1급(바로): 결제·가입·로그인이 막힘, 개인정보·숨긴 주소 노출, 화면이 안 열림

- 3급(모아서): 간격·색·글자 크기 어긋남, 문구 다듬기
- 고치는 길: 공통 코드는 고쳐서 새 버전 → 시험 모드 확인 → 운영 배포 → 운영 화면 다시 확인. 디자인 위젯은 디자인 모드 저장 → 사장님 게시. 관리자 설정은 바로 저장 후 확인.
