## 결제·혜택 (운영에서 직접)
- 결제수단: 실시간계좌이체·휴대폰·신용카드·가상계좌·무통장 노출. **카카오페이·토스페이는 PG 심사 중**이라 안 보임
- 결제 심사 준비 **5/5**, 정기구독 1개 연결
- 쿠폰+적립금+추천인: 20,000 − 1,000 − 500 = 18,500원, 적립 예정 1,850P(실결제 10%) → 취소 시 적립금·쿠폰 복원 ✅
- 10% 적립: 구매확정 시 지급(10/31 +42,390 확인). 기준 = 실제 결제 금액(쿠폰·적립금 사용분 제외)
- 추천인: 링크 → 결제 화면 자동 입력 → 주문 데이터 저장 ✅ / **보상은 자동 지급 없음**(관리자 수동 절차, 10/31 문서)
