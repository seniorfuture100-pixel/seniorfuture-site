## 운영 배포 (공통 코드)
- v1.0.157 → **v1.0.163** (11/2 02시) → **v1.0.165** (11/2 03시, 인사이트 속도). 매번 Header Code 저장 확인 → 로그아웃 접속 버전·noindex 확인 → main 푸시
- 속도(느린 휴대폰 4G·CPU 4배, 운영): 우리 코드 때문에 인사이트가 아임웹보다 10~20초 더 멈추던 것(전체 글 8쪽을 열자마자 받아 160개를 한꺼번에 붙임)을 '첫 쪽 끝에 가까워질 때'로 바꿈 → 멈춤 24.5초 → 6.6초, 준비 103초 → 32.5초. 실제 크롬에서 열 때 추가 받기 0건, 스크롤하면 12 → 107개 확인. Codex '배포 가능'
- 측정 흔들림 주의: 같은 조건에서 홈 '아임웹만' 멈춤이 4.6초 → 10.5초로 오갈 만큼 TBT 가 크게 흔들려요. 홈 코드는 v1.0.163 뒤로 안 바뀌었고, 배포 뒤 홈 14.3초도 같은 흔들림 범위로 판단
- 배포 뒤(v1.0.165) 손님 화면 전수: **모두 정상**
- 아임웹 자체가 느린 화면: 커뮤니티(우리 코드 빼도 첫 화면 32초)·홈(6초) — 상품 그림 크기·아임웹 스크립트 몫이라 코드로는 한계. 목표(2.5초) 미달, 그림 용량 줄이기·홈 섹션 줄이기가 다음 후보
- 바뀐 것: 계정 바꿈 시 이전 주문 노출 차단 · 환불 시 강의실 권한 회수 · 추천인 코드 자동 입력 복구 · 옵션 선택 오류 · 재구매 수강 기간 · 로그인 뒤 강의실 복귀 · 검색/주문 상세 무한 다시 그리기 · 홈 강의 가격 갱신 · CDN 대체 주소 · 결제 화면 접근성 2건 · 매일 점검 도구 2건

## 결제·혜택 (운영에서 직접)
- 결제수단: 실시간계좌이체·휴대폰·신용카드·가상계좌·무통장 노출. **카카오페이·토스페이는 PG 심사 중**이라 안 보임
- 결제 심사 준비 **5/5**, 정기구독 1개 연결
- 쿠폰+적립금+추천인: 20,000 − 1,000 − 500 = 18,500원, 적립 예정 1,850P(실결제 10%) → 취소 시 적립금·쿠폰 복원 ✅
- 10% 적립: 구매확정 시 지급(10/31 +42,390 확인). 기준 = 실제 결제 금액(쿠폰·적립금 사용분 제외)
- 추천인: 링크 → 결제 화면 자동 입력 → 주문 데이터 저장 ✅ / **보상은 자동 지급 없음**(관리자 수동 절차, 10/31 문서)
