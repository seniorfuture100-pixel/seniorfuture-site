# 07. 확인 못 한 것과 이유 (11/2 밤 → 11/3 갱신)

11/3: 사장님 지시("승인 목록은 넘어가고 끝까지")에 따라 승인이 필요한 일(시험 신청·주문서 열기·배포·게시·관리자 글 수정)은 하지 않고 건너뜀. 로그인 화면은 앱 브라우저의 관리자 로그인(`seniorfuture.imweb.me`)으로 읽기만 함.

## 참고 — 측정 조건 차이
- 운영 주소: 측정은 `https://seniorfuture.kr`, 속도·스크롤 도구(`perf.js`·`scroll.js`)는 원래대로 `seniorfuture.imweb.me`(같은 사이트, 지난 결과와 같은 조건으로 비교하려고).
- 운영 공통 코드는 측정 시점 **v1.0.199** (지시서의 v1.0.198 아님 — 모든 화면 97/97 에서 `seniorfuture-site@v1.0.199` 를 불러옴).
- 지시서의 상세 화면 `/course/?idx=83, 86, 94~102` 는 손님에게 **301 → 홈**(판매 숨김 상품으로 보임). `perf.js` 의 `live99`(`/live/?idx=99`)도 홈으로 넘어가서 그 줄은 홈 값임.
