## 4. 라이브 신청
- **회원만 신청**(v1.0.240): 아임웹엔 상품별 '회원 전용'이 없어(전체 비회원 구매를 끄면 교육 결제까지 막힘) 우리 코드로 — 비회원이 '무료로 신청하기'를 누르면 로그인 화면 → 로그인 뒤 그 상품으로. PC·휴대폰(아래 버튼 → 옵션 창) 확인.
- 주문서: 주문 상품 → 주문자 정보 → 신청하기(결제 수단·추천인·적립금 칸 없음).
- **완료 화면**(v1.0.236~238): '신청이 완료되었습니다! / 강의 안내는 톡방에서 제공드릴 예정이니 마감 전 꼭 바로 입장해주세요!' + 노란 **'소통방 입장'** 한 줄(홈으로·마이페이지 위).
  - 링크 = 상품 설명 `[톡방]` 다음 줄 주소(`[톡방 비밀번호]` 있으면 버튼 위에 표시). 라이브에 `[톡방]`이 없으면 **예시로 카카오톡 채널(pf.kakao.com/_ZYaLG)**.
  - 주문번호·'무료'를 화면이 뜨자마자 표시, 푸터도 카드와 같이 표시(전엔 페이지 전체 로드 뒤라 늦었어요).
