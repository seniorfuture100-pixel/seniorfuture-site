# 강의실 운영 안내 (관리자용, 2026-10-29)

강의를 열 때 **상품만 등록하면** 나의 강의실 · 강의실 · 톡방 버튼 · 영상이 자동으로 연결돼요.
강의마다 페이지·회원 그룹·위젯을 만들 필요는 없어요.

## 흐름
```
상품 등록(상세 설명에 칸 작성)
  → 마이페이지 › 학습 › 나의 강의실: 결제한 강의 카드(수강 기간 · D-day · 강의실 입장 · 톡방 입장)
  → 강의실 입장 = 공용 강의실 /class?idx=상품번호
  → 결제(0원 신청 포함)한 회원에게만 커리큘럼 · 바로보기(영상 창)
```

## 1. 상품 등록할 때 (관리자 › 쇼핑 › 상품)
상세 설명에 아래 칸을 `[제목]` 한 줄 + 내용 줄로 적어요.

```
[소개]
강의 소개 글

[프로그램]
총 6회 · 회당 90분 · 온라인
1회차 오리엔테이션 (90분)
- 세부 내용
2회차 제목 (90분)

[강사]
홍길동

[수강 기간]
2026.11.01 - 2026.12.31        ← 기수제(고정 날짜)
결제일부터 90일                  ← 온라인 VOD(결제일 기준, '3개월'도 가능)

[톡방]
https://open.kakao.com/o/…     ← 오픈채팅 주소

[강의 영상]
1회차 https://vimeo.com/…      ← 영상이 생길 때마다 한 줄씩
```

- `[수강 기간]` → 상품 화면 구매 상자에 '수강 기간' 한 줄로 보여요.
- `[톡방]` · `[강의 영상]` → **손님 화면(상품 상세)에는 안 보여요.** 나의 강의실·강의실에서만 버튼으로 나와요.
- 영상 주소를 넣은 회차만 '바로보기', 없는 회차는 '공개 예정'이에요.
- 상세 설명 바깥쪽 '프로그램' 회차 줄에 링크를 걸면 누구나 보는 '미리보기'가 되니, 전체 영상 주소는 꼭 `[강의 영상]` 칸에만 적어요.

## 2. 영상 올리기 (강의가 끝날 때마다)
1. 강사 → 강의별 드라이브 폴더에 영상·자료집 업로드 (`3회차_제목.mp4`처럼 이름 맞추기)
2. 관리자 → Vimeo 강의 폴더에 업로드, '우리 사이트에서만 재생' · '공개 목록에서 숨김' 설정
3. 관리자 → 상품 상세 `[강의 영상]`에 `3회차 https://vimeo.com/…` 한 줄 추가 → 저장하면 바로 반영

자료와 소통은 강의 톡방에서 해요.

## 3. 바뀌는 것 · 자동인 것
| 상황 | 할 일 |
|---|---|
| 톡방 주소 바뀜 | 상품 상세 `[톡방]` 주소만 바꾸기 |
| 영상 교체 | `[강의 영상]` 줄 주소 바꾸기 (또는 Vimeo '영상 교체') |
| 환불·취소 | 없음 — 나의 강의실·강의실에서 자동으로 빠져요 |
| 수강 기간 끝남 | 없음 — '수강 종료'로 바뀌고 버튼이 꺼져요 |
| 다음 기수 | 지난 상품 **복제** → 이름·`[수강 기간]`만 수정 |

## 4. 주의
- 수강 기간 중인 상품은 **'숨김'으로 바꾸지 마세요.** 강의실이 상품 상세를 읽어 오는데, 숨긴 상품은 볼 수 없어 강의실이 빌 수 있어요(검증 필요). 모집이 끝나면 품절·판매 기간 종료로 두고, 모든 수강 기간이 끝난 뒤 숨김.
- 공용 강의실 페이지(디자인 모드 '강의실', 주소 `/class`, 메뉴 숨김 · 로그인 사용자만)와 그 안 코드 위젯은 고치지 마세요.
- 영상 보호는 Vimeo의 '우리 사이트에서만 재생' 설정이 맡아요(영상 주소는 상품 페이지 원본에 남아요).
