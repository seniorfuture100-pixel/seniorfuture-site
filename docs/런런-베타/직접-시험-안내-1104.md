# 런런 직접 시험 안내 (11/4 셋팅)

> **11/5 정리:** 시험이 끝나 상품 105~109 를 다시 **숨김**으로 돌렸어요(진열·검색은 끈 그대로, 107 은 0원·옵션 3개 그대로). 다시 시험하려면 아래 5장 '지금' 상태로 판매중만 바꾸면 돼요.

시험 상품 5개를 **판매중 · 교육 목록 진열 끔 · 사이트 검색 끔**으로 열어 뒀어요.
교육 목록·홈·검색에는 안 나오고 **아래 주소로만** 들어갈 수 있어요. 숨김·삭제는 하지 않았어요.

## 1. 상품 설명 맨 아래 `[강의실]` 두 줄이 하는 일

```
[강의실]
/learn-run
```

- **상품 상세 화면:** 두 줄은 화면에 안 보여요(우리 코드가 숨김).
- **나의 강의실(마이페이지):** 그 상품을 결제한 회원 카드의 **'강의실 입장'** 버튼 주소가 `/class?idx=상품번호` 대신 **`/learn-run`**(런런 강의실)이 돼요.
- `[강의실]` 제목 줄 없이 `/learn-run` 한 줄만 쓰면 아무 일도 안 일어나요. 두 줄이 같이 있어야 해요.
- 주소는 `/`로 시작하는 우리 사이트 주소만 받아요(`?` 들어간 주소, 외부 주소는 무시).
- 버튼 주소는 30분 동안 저장돼요(5분 지나면 나의 강의실이 다시 읽어 바로잡음). 넣고 빼고 바로 확인하려면 **시크릿 창**.
- **수강 등록 자체는 이 두 줄과 무관**해요. 등록은 런런 강좌의 '아임웹 상품 연결'로 일어나요. 두 줄은 '버튼이 어디로 가느냐'만 정해요.
- 상품 설명에 `[수강 기간]`이 있으면 카드에 기간·D-day가 나오고, 끝나면 '수강 기간 종료'로 바뀌어요. 없으면 '수강 기간은 교육 정보에서 확인해 주세요'.
