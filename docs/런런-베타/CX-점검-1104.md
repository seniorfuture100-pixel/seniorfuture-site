# 런런 CX 점검 (11/4 밤) — 상품별 운영 기준으로 정리

**운영 원칙(11/4 사장님 결정):** 기수는 쓰지 않아요. **상품 1개 = 런런 강좌 1개.** 회차가 바뀌면 새 상품·새 강좌를 만들어요.
나의 강의실 '강의실 입장'은 런런 전체(`/learn-run`)로 가도 돼요. 들어가면 '내 학습'이 먼저 보이도록 우리 코드로 맞춰요.

점검 방법: 관리자 겸 회원 계정, 앱 안 브라우저, 휴대폰 크기(375).
흐름: 상품 상세 → 신청 창 → 주문서 → 완료 → 나의 강의실 → 강의실 입장 → 런런 → 영상

## 다듬으면 좋은 것

- 완료 화면 주 버튼 '마이페이지' → '강의실 바로 가기'.
- 0원 신청 주문서: 제목 '주문결제'·'적립금 사용' 칸 → 0원일 땐 '신청서', 적립금 칸 숨김.
- 이미 신청한 교육을 또 신청해도 경고 없음 → "이미 신청한 교육이에요 · 강의실 가기".
- 런런 '내 학습': 안 본 강좌도 '이어보기' → '학습 시작'(런런 요청). 주소가 늘 `/learn-run` 이라 새로고침하면 처음 화면(→ 1번 처리로 '내 학습').
- 런런 '강좌 목록'에 신청 안 한 강좌도 '수강 전·회원 전용'으로 보임 → 신청한 강좌만 보이게(런런 요청), 그전까지는 첫 화면을 '내 학습'으로.
- 상품 설명에 '어디서·어떻게 듣는지'(나의 강의실 → 강의실 입장)와 수강 기간을 꼭 넣기(상품-상세-등록-안내 참고).
