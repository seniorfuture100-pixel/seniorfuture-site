# 런런 강의실 UI/UX 설계 (11/5)

시니어퓨처 교육을 듣는 손님이 **결제 → 강의실 → 수강 → 수료**까지 헤매지 않게, 런런 화면을 시니어퓨처 디자인 시스템으로 맞춘 설계예요.
기준: 사이트 토큰(`site/src/css/qa/11-1102-uiux.css`) = 당근 SEED 디자인 시스템(DESIGN 당근.md). 코드: `site/src/js/patch/26h-learnRunSkin.js` (v1.0.220, 운영 반영).

## 1. 운영 원칙

- **상품 1개 = 런런 강좌 1개.** 기수 옵션은 쓰지 않아요. 회차가 바뀌면 새 상품·새 강좌.
- 나의 강의실 '강의실 입장' → `/learn-run`(런런 전체). 들어가면 **'내 학습'이 먼저** 보여요(우리 코드).
  런런이 지난번에 보던 레슨을 기억하면 그 레슨이 바로 열려요(이어 보기).
- 수강 기간은 두 곳을 같게: 상품 설명 `[수강 기간]`(나의 강의실 카드 표시) + 런런 강좌 설정(실제 열람 제한).

## 2. 손님 흐름

| 단계 | 화면 | 손님이 알아야 할 것 | 장치 |
|---|---|---|---|
| 1 | 상품 상세 | 어디서·언제까지 듣는지 | 상세 설명에 "결제 후 마이페이지 › 나의 강의실 › 강의실 입장" + `[수강 기간]` |
| 2 | 신청 완료 | 바로 들을 수 있다는 것 | 완료 화면 '마이페이지' 버튼(→ 나의 강의실 탭) |
| 3 | 나의 강의실 | 내 강의, 남은 기간 | 카드: 상태칩·기간·D-day·'강의실 입장' |
| 4 | 런런 내 학습 | 이어서 볼 강의 | 첫 화면 고정, 맨 위 카드만 주황 버튼 |
| 5 | 영상 | 지금 몇 강인지, 다음 강 | 레슨 제목 22px, 커리큘럼 시트 |
| 6 | 수료 | 수료증 받는 곳 | 런런 '내 수료증'(수료증은 추후) |

## 4. 우리가 못 바꾸는 것 → 런런에 요청

1. 안 본 강좌도 '이어보기' → **'학습 시작'**으로.
2. '강좌 목록'에 신청 안 한 강좌가 '수강 전·회원 전용'으로 보임 → 신청한 강좌만, 또는 '교육 보러 가기'로 상품 연결.
3. 영상 오류 화면 문구 겹침(휴대폰).
4. 주소가 늘 `/learn-run` → 화면마다 주소(새로고침·뒤로 가기·공유).
5. 강좌별 바로 가기 주소 → 나의 강의실 카드에서 그 강좌로 바로.
6. 위젯 스크립트를 `/learn-run` 에서만, 비동기로 불러오기(휴대폰 속도).

## 5. 운영자가 채울 것 (강좌 등록 체크리스트)

- 강좌 이름 = 상품 이름과 같게(앞 [CX TEST] 같은 머리말 없이).
- 강좌 썸네일 = 상품 대표 이미지(16:9). 기본 남색 썸네일 쓰지 않기.
- 레슨 이름: "1강. ○○○" 처럼 번호 + 한 줄.
- 레슨 소개 1~2줄(비우면 칸이 숨어요).
- 상품 설명 맨 아래: `[강의실]` 다음 줄 `/learn-run`, `[수강 기간]` 채우기.
