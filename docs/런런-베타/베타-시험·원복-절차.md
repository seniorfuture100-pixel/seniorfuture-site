## 2-1. 설치 뒤 관찰 (11/3)

- 설치: 11/3 14:20, 무료 체험 D-14 → **11/17 무렵 종료**. 결제 내역 없음. '연간 결제 2개월 무료' 팝업과 요금제 화면(Starter 69,000원/월 할인가 등)은 누르지 않음.
- 앱 관리 '연동 완료' 14개(런런 추가).
- **런런이 사이트 모든 화면 `<body>` 맨 앞에 위젯 스크립트를 넣음**: `<script data-site-code=… src="https://learn-run.me/learnrun-widget.iife.js">`
  - async/defer 없음(그 자리에서 화면 그리기를 멈추고 받음), 2.6MB(gzip 672KB), `Cache-Control: no-cache`(매번 서버에 확인).
  - 화면을 그리는 건 주소가 `/learn-run` 으로 시작할 때만(`#learnrun-app` 을 헤더 아래에 만듦, iframe 아님). 다른 화면에는 보이는 변화 없음.
  - 속도(`tools/check/lms-speed.js`, 휴대폰·CPU 4배 느리게·첫 방문, 막음 vs 그대로, 3회 중앙값): 메인 스레드 막힘(TBT) **+265~+501ms** (홈·교육·상품 82). 첫 화면(FCP/LCP)은 ±300ms 안에서 오르내려 측정 흔들림과 구분 안 됨.
  - 우리 공통 코드로는 이 스크립트를 늦출 수 없음 → 정식 도입 시 런런에 'async 또는 /learn-run 에서만 로드' 요청.
- `compare` 에 이 스크립트가 '런런 흔적'으로 잡힘. 앱 연동을 해제하면 사라져야 정상.
- 아임웹 회원 2명·회원 그룹 4개(VOD 수강 · 시니어트렌드 2027, 무료 라이브 그룹 10.30, 고고싱이다, 수강 · 장기요양기관 운영 실무 1기)가 런런으로 동기화됨 → 원복 3번(회원 정보 삭제 요청) 대상.
- 런런 환경설정: 허용 도메인에 `seniorfuture.kr` 자동 등록(허용 도메인만 접근 ON), 테마 색, 커스텀 CSS(학생 화면·위젯에 적용, `@layer` 라 !important 없이 덮어씀, `.lr-*` 선택자와 `--color-*` 변수), 콘텐츠 최대 너비(px).
- 강좌 옵션: 공개 대상 = 전체 / 아임웹 그룹 / 아임웹 상품 연결(기수 = 상품 옵션) / 선착순 승인 정원(상품·그룹과 같이 못 씀), 무료 공개 강의 수, 순차 수강, 수료 기준 %, 과제 합격 필수, 수료증 발급.
- 별개 사항: 상품 85가 이번 비교에서 판매 화면 301(홈으로) + 사이트맵에서 빠짐. 런런과 무관해 보임(앱이 상품을 바꾸는 기능 없음) — 사장님 확인 필요.
