## 2. 강의를 실제로 여는 순서 (영상이 생기면, 상품마다)

지금 판매 중인 상품(82 오프라인 스터디, 103 멤버십, 84 무료 라이브)엔 올릴 영상이 아직 없어요. 그래서 강좌를 **비공개로 미리 연결**해 두었어요(그사이 산 분도 런런에 수강생으로 쌓이는지는 첫 강의 공개 때 '수강생' 숫자로 확인).

1. 런런 › 강좌 관리 › 강좌(168 또는 169) › **새 강의 추가**: 영상 올리기 · 강의 이름 "1강. ○○○" · 소개 1~2줄.
2. 썸네일: 상품 대표 이미지(16:9)를 올려요(기본 남색 그림 안 쓰기).
3. 공개 설정 **'지금 공개'** → 저장.
4. 아임웹 상품(82 / 103) 상세 설명 맨 아래에 두 줄:
   ```
   [강의실]
   /learn-run
   ```
   (수강 기간이 있으면 `[수강 기간]` 칸도 채우기 — 나의 강의실 카드에 기간·D-day)
5. 확인: 그 상품을 산 회원으로 나의 강의실 → '강의실 입장' → '내 학습'에 강좌가 보이고 재생되는지. 런런 강좌 편집 › '수강생' 숫자 = 아임웹 주문 수.

새 상품(예: 12기)을 만들 땐 런런에도 새 강좌를 만들고 '아임웹 상품 연결' → 상품 동기화 → 그 상품 선택.

## 4. 런런 회사에 요청할 것 (설계서 4장과 같음)

'학습 시작' 문구, 신청한 강좌만 목록에, 오류 화면 글자 겹침, 화면별 주소, 강좌별 바로 가기 주소, 위젯을 /learn-run 에서만 불러오기, 잠긴 레슨의 '✓ 완료' 표시.

## 5. 아직 안 한 것 (이유)

- 신청 창 수량 −/+ 칸: 코드에 "개수는 옵션 줄에서만" 일부러 남긴 규칙이 있어(103 옵션 등) 건드리면 다른 상품이 깨질 수 있어요. 교육 상품 옵션을 정리한 뒤에.
- 이미 신청한 교육 다시 신청 경고: 상품 화면마다 주문 목록을 새로 받아야 해서(속도) 보류.
- 연락처 없는 회원·비회원 주문서 칸 숨김 문제, 카드 결제(토스 조건부 승인): 결제 쪽 일이라 따로.
- 아이폰 사파리·일반 회원 휴대폰 실제 재생: 사장님 휴대폰으로 첫 강의 공개 때.

- 런런 168(11기 스터디)·169(멤버십 다시보기)에 **예시 영상** 1강씩('예시 영상 — 시니어퓨처 네트워킹 소개', 2:11, 영상 보관함의 네트워킹 광고소개) → **공개**.
- 상품 82·103 상세 맨 아래 `[강의실]` / `/learn-run` 추가(공개 상품 HTML 로 확인). 82의 옛 `[강의 영상]`은 견본 유튜브(Big Buck Bunny)라 잃는 것 없음. 톡방 버튼은 그대로.

손님 흐름 점검(휴대폰 375, 회원 정동호, 상품 103 '1회 수강 신청'):

| 단계 | 결과 |
|---|---|
| 상품 상세 → 신청 창 | ✓ '정기구독 신청 / 1회 수강 신청' 두 버튼, 시트 '수강 옵션' 24,900원 |

| 관리자 입금 확인 | ✓ 나의 강의실 카드 '수강 중 · D-29 · 2026.11.05-12.04 · 강의실 입장(/learn-run)' |

| 런런 직접 등록 후 | ✓ 강의 화면 잠김 없이 열림(예시 영상·소개 보임). 다만 '내 학습' 목록엔 바로 안 보였어요(목록이 이전 내용으로 남아 있는 것으로 보여요 — 런런 문의) |
| 무료 라이브 84 | ✓ 상세·남은 시간·무료 신청 버튼 정상(런런 미연결, 지금 방식 그대로) |

**운영 규칙(무통장):** 입금 확인을 누른 뒤 → 런런 › 수강생 관리 › 그 회원 '수강등록' › 강좌 선택(82 → 168, 103 → 169). 휴대폰결제(PG)·0원 주문은 자동 등록(0원은 11/4 확인, 휴대폰결제는 미확인).
**런런에 문의:** 무통장 '입금 확인(결제 완료)'도 자동 등록되게, 직접 등록한 수강도 '내 학습'에 바로 보이게.

정리: 시험 주문 202611052843636(103)·202611046206810(106) → '취소 승인만 처리'로 **취소 완료**(실제 입금이 없어 환불 금액 기록 안 함, 관리자 화면에 '환불 처리 대기' 표시는 남음). 런런 직접 등록도 '수강 취소'로 뺐어요.
